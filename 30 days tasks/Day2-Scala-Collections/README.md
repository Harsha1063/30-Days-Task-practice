# Day 2 - Scala Collections Practice

## Objective

Practice Scala collections and process sales data without using Spark.

## Topics Covered

### 1. List

Used:
- `map`
- `filter`
- `flatMap`
- `reduce`

### 2. Vector

Used `Vector` to store indexed customer records.

Vector is useful because it provides fast indexed access while remaining immutable.

### 3. Map

Used `Map` to store:
- Product quantities
- Product prices

### 4. For-Comprehension

Combined customers and their orders with product prices.

### 5. Daily Sales Summary

Processed daily orders without Spark and calculated:
- Product quantity
- Product revenue
- Grand total sales

## Result

Grand Total Sales: ₹285000

## Technology

- Scala
- Scala Collections
- No Spark
