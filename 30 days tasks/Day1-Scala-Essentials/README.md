# Day 1 - Scala Essentials

## Topics Covered

- `val`, `var`, and `lazy val`
- Immutable Scala collections
- For-comprehension with `yield`
- List, Vector, Set, and Map
- Traits and implementation
- Student grade processing using Scala collections

## Program

`Day1ScalaEssentials.scala`

The program demonstrates:

1. Variables and immutable collections
2. For-comprehension using students and marks
3. Collection comparison
4. Logger trait with two implementations
5. Student grade processor
